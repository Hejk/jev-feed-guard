# JevFeedGuard（清净流）

用 [TypeSafe AI 的 Jev](https://typesafe.ai)（System One 判断模型）过滤信息流里**你不感兴趣的内容和广告**的 Chrome 扩展。当前支持**小红书、B站**网页版，微博、抖音等通过适配器持续扩展（多平台适配器架构：核心引擎一套，每个平台只加一个适配器）。

**BYOK（自备 Key）**：Jev API Key 由你自己在 [console.typesafe.ai/keys](https://console.typesafe.ai/keys) 创建并粘贴到扩展设置页。Key 只存在你的浏览器本地，请求只发给 `api.typesafe.ai`。没有中间服务器、没有遥测。

设计借鉴了 [fazlerocks/jev-adblock](https://github.com/fazlerocks/jev-adblock)：候选粗筛 → 结构化描述 → 批量 Choice 请求 → 代码拥有全部阈值 → 指纹缓存 → 纠错 pin。本项目的差异化：针对小红书无限滚动 SPA 加了 MutationObserver 持续监听，并增加 "兴趣判断"（Noul），不止过滤广告。

## 功能



* **多平台适配器**：核心引擎（Jev 判定 / 缓存 / 护栏 / 角标）跨平台复用；每个平台只贡献 `match / collect / extract` 三件事。**B站首页广告零成本拦截**：广告卡（无视频链接 / 带"广告·推广"字样 / 作者位显示"N万人感兴趣"）由适配器直接识别、不调用 Jev 就隐藏（实测 10 张推荐卡含 2 条广告）。

* **广告 / 推广过滤**：Jev 用 Choice 判断每条笔记属于 `赞助广告 / 软广带货 / 官方营销 / 普通内容 / 界面元素` 五类，商业概率达标且压过普通内容一定边际才隐藏。

* **不感兴趣内容过滤**：Jev 用 Noul 判断 "你对这条笔记感不感兴趣"——`≥0.8 隐藏`、`0.5–0.8 折叠成一行（可展开恢复）`、`<0.5 保留`。

* **fail-open**：API 出错、超预算、熔断、置信度不足时一律不动作，宁可漏杀不可误杀。

* **缓存与纠错**：同一笔记 7 天内不重复调用；点 "展开" 会把该笔记永久 pin（不再折叠）；同一作者连续 5 条 "不感兴趣" 后本会话内直接折叠该作者（省 token）。

* **护栏**：只在 `xiaohongshu.com` / `bilibili.com` 生效；含密码框 / 支付 iframe 的页面不分析；每日 token 预算（默认 500 万 ≈ \$0.21）；连续失败自动熔断 10 分钟。

* **成本**：一次批量请求约 10k token ≈ \*\*$0.0004**；缓存命中零成本。新用户注册送 $5（约 1.2 亿 token）。

## 安装（解压加载，无需构建）



1. `git clone` 或解压本项目到本地。

2. 打开 Chrome → `chrome://extensions` → 打开右上角 "开发者模式"。

3. 点 "加载已解压的扩展程序"，选择本项目根目录（含 `manifest.json` 的文件夹）。

4. 点扩展图标打开设置页，粘贴 API Key，勾选隐私说明，点 "保存并测试"—— 绿色 "连接成功" 即就绪。

## 必做：按你的真实页面校准选择器

当前 `src/content/selectors.js` 已按 2026-09-23 实测校准过（`.note-item` / `a.title` / `a.author`），正常情况下无需改动；只有小红书改版导致选择器失效时才需要重新校准。校准步骤：



1. 浏览器打开 `https://www.xiaohongshu.com/explore`。

2. 右键任意一张笔记卡片 → **检查**（Inspect）。

3. 确认 / 修改 `SELECTORS` 里的四个关键项：

* `CARD`：卡片最外层容器（信息流里一张卡片的根元素）

* `TITLE`：标题元素

* `AUTHOR`：作者名元素

* `TAGS`：标签元素

1. 保存文件后，到 `chrome://extensions` 点本扩展的**刷新**按钮，再刷新小红书页面。

> 提示：信息流卡片基本都长一个样，改一个选择器通常整页生效。

## 使用



* 打开小红书 explore 页，扩展会自动分析新出现的卡片。

* 被隐藏的卡片直接消失；被折叠的显示一行灰色细条（"…（Jev 认为你可能不感兴趣）\[展开]"）。

* 点 "展开" 恢复该笔记，并永久记住不再折叠它。

* 设置页可随时调阈值：


  * **广告概率阈值**（默认 0.85）：商业概率高于它才可能隐藏

  * **广告 - 内容边际**（默认 0.2）：商业概率必须压过普通内容这么多，防误杀

  * **不感兴趣隐藏线**（默认 0.8）：Noul ≥ 它直接隐藏

  * **折叠下限**（默认 0.5）：Noul 在 0.5–0.8 之间折叠

  * **最低置信度**（默认 0.6）：低于它一律不动

## 隐私与合规



* 发送给 Jev 的只有：页面域名与标题、笔记的标题 / 作者 / 标签 /≤150 字摘要、粗筛信号（是否有赞助角标 / 价格 / 购买按钮）。

* **绝不发送**：笔记正文、图片、完整 URL、cookie、表单值、任何个人数据。

* 含密码输入框或支付 iframe 的页面完全不分析。

* 本扩展非官方产品，与小红书无关联；仅供个人学习研究，请遵守平台规则与当地法律法规。
