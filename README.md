# JevFeedGuard（清净流）

用 [TypeSafe AI 的 Jev](https://typesafe.ai)（System One 判断模型）过滤信息流里**你不感兴趣的内容和广告**的 Chrome 扩展（MV3，无需构建）。当前支持**小红书、B站网页版**；微博、抖音、知乎等通过适配器持续扩展——核心引擎一套，每个平台只加一个适配器。

**仓库**：<https://github.com/Hejk/jev-feed-guard>（Public，GPL-3.0）

**BYOK（自备 Key）**：Jev API Key 由你自己在 [console.typesafe.ai/keys](https://console.typesafe.ai/keys) 创建并粘贴到扩展设置页。Key 只存在你的浏览器本地，请求只发给 `api.typesafe.ai`。没有中间服务器、没有遥测。设置页里 Key 保存后会用占位符显示（不清空、不重复输入），可随时清除。

设计借鉴了 [fazlerocks/jev-adblock](https://github.com/fazlerocks/jev-adblock)：候选粗筛 → 结构化描述 → 批量 Choice 请求 → 代码拥有全部阈值 → 指纹缓存 → 纠错 pin。本项目的差异化：针对小红书/B站无限滚动 SPA 加了 MutationObserver 持续监听 + 粘性重应用（抗 React 重渲染），并增加"兴趣判断"（Noul），不止过滤广告。

## 功能

* **多平台适配器引擎**：核心引擎（Jev 判定 / 缓存 / 护栏 / 角标）跨平台复用；每个平台只贡献 `match / collect / extract` 三件事。**B站首页广告零成本拦截**：广告卡（无视频链接 / 带"广告·推广"字样 / 作者位显示"N万人感兴趣"）由适配器直接识别、不调用 Jev 就隐藏。

* **广告 / 推广过滤**：Jev 用 Choice 判断每条内容是 `赞助广告 / 软广带货 / 官方营销 / 普通内容 / 界面元素` 五类，商业概率达标且压过普通内容一定边际才隐藏。

* **不感兴趣内容过滤**：Jev 用 Noul 判断"你对这条内容感不感兴趣"——`≥0.8 隐藏`、`0.5–0.8 折叠成一行（可展开恢复）`、`<0.5 保留`。

* **fail-open**：API 出错、超预算、熔断、置信度不足时一律不动作，宁可漏杀不可误杀。

* **缓存与纠错**：同一内容 7 天内不重复调用；点"展开"会把该内容永久 pin（不再折叠）；同一作者连续 5 条"不感兴趣"后本会话内直接折叠该作者（省 token）。

* **护栏**：只在 `xiaohongshu.com` / `bilibili.com` 生效（`www.` 前缀与裸域名均支持）；含密码框 / 支付 iframe 的页面不分析；每日 token 预算（默认 500 万 ≈ \$0.21）；连续失败自动熔断 10 分钟。

* **成本**：一次批量请求约 10k token ≈ **\$0.0004**；缓存命中零成本。新用户注册送 \$5（约 1.2 亿 token）。

## 界面与交互

* **右下角悬浮角标**：实时显示 `分析 / 折叠 / 隐藏` 三个累计数字；点角标上的 **×** 可临时隐藏，滚动页面自动恢复。
* **折叠条**：被折叠的内容变成一行灰条——**左侧带 4px 红色竖线**，文字如"…（Jev 认为你可能不感兴趣）"，右侧蓝色"**展开**"按钮。点"展开"恢复该内容并永久记住。
* **广告卡**：被隐藏的广告直接消失，不留痕迹。
* **设置页（点扩展图标打开）**：API Key 输入/保存/清除（保存后占位符显示）、隐私说明勾选、"连接测试"、最近判定面板（最近 6 条 Jev 判定：标题 / 动作 / 理由 / Noul / 广告概率）、阈值调节、"我不喜欢的内容"自定义文本框。

## 个性化：不想看什么，用大白话告诉它

* 设置页的 **"我不喜欢的内容"** 文本框：直接写"吃播、大胃王""卖儿童玩具的""标题党、博眼球""装傻充愣"这类自然语言，保存后会自动注入 Jev 的问题指令（Noul）并生成关键词规则。
* **手动规则优先**：命中关键词直接隐藏/折叠，不调用 Jev（省 token、行为可预期）；平台适配器确认的广告卡（`ad_card` 信号）直接隐藏，优先级最高。

## 安装（解压加载，无需构建）

1. `git clone https://github.com/Hejk/jev-feed-guard` 或下载解压到本地。
2. 打开 Chrome → `chrome://extensions` → 打开右上角"开发者模式"。
3. 点"加载已解压的扩展程序"，选择本项目根目录（含 `manifest.json` 的文件夹）。
4. 点扩展图标打开设置页，粘贴 API Key，勾选隐私说明，点"保存并测试"——绿色"连接成功"即就绪。

> 更新代码后：到 `chrome://extensions` 点本扩展卡片上的 **⟳ 刷新** 按钮，再刷新打开的页面。已打开的旧页面会报 "Extension context invalidated"（v0.3.1 起已静默），F5 后即恢复正常。

## 使用

* **小红书**：打开 `https://www.xiaohongshu.com/explore`，扩展自动分析新出现的卡片，向下滚动持续生效。
* **B站**：打开 `https://www.bilibili.com/` 首页，同样自动分析；广告卡直接消失，不感兴趣的视频折叠成灰条。
* 角标数字上涨 = 判定在后台正常产生；页面没变化时先确认扩展已 ⟳ 刷新 + 页面已 F5。

│   └── content/
│       ├── selectors.js       # ★ 各平台 DOM 选择器配置层（平台改版时改这里）

## 隐私与合规

* 发送给 Jev 的只有：页面域名与标题、内容的标题 / 作者 / 标签 / ≤150 字摘要、粗筛信号（是否有赞助角标 / 价格 / 购买按钮）。
* **绝不发送**：内容正文、图片、完整 URL、cookie、表单值、任何个人数据。
* 含密码输入框或支付 iframe 的页面完全不分析。
* 本扩展非官方产品，与小红书/B站无关联；仅供个人学习研究，请遵守平台规则与当地法律法规。
